# World
世界聖經 — 我的旅行 App：所有旅行的行前準備、每日行程、旅途紀錄、足跡地圖都在這裡。

- 網址：https://fuwei0618-cmd.github.io/World/
- iPhone：用 Safari 打開 → 分享 → 加入主畫面

## 檔案
| 檔案 | 用途 |
|---|---|
| `index.html`、`app.js`、`app.css` | App 本體 |
| `presets.js` | 各國預設：常用 App、緊急電話、行李項目、地圖（中國用高德、韓國用 NAVER） |
| `trips/` | 「發布給團員」時由 App 自動上傳的行程（聯絡人與保險已加密） |
| `samples/` | 範例行程 |
| `sw.js` | 離線快取 |

## 資料存在哪
- 行程與紀錄（照片、影片、錄音）存在手機裡，不會上傳。設定 → 匯出全部資料 可備份。
- 只有按「發布給團員」的行程會進到 `trips/`，紀錄永遠不會發布。
